# 💅 Esmalte Api

Esta é uma api divertida e criativa que utiliza inteligência artificial para gerar **nomes estilosos de esmaltes a partir de cores em hexadecimal** e **cores hexadecimais a partir de nomes de esmalte**. Algo que começou como uma piada no trabalho e agora é uma realidade.

---

Link para documentação:

---

## 🚀 Funcionalidades

- **Gerar nome do esmalte**: Recebe uma cor hexadecimal e retorna um nome estiloso e criativo em português.
- **Gerar cor do esmalte**: Recebe um nome de esmalte e retorna a cor hexadecimal correspondente.
- **Integração com IA**: Utiliza um modelo de linguagem para gerar resultados dinâmicos com base em prompts.
- **API JSON simples**: Interface de uso simples via rotas POST com JSON.

---

## 🛠️ Tecnologias Utilizadas

- **Node.js**: Ambiente de execução para JavaScript no servidor.
- **Express.js**: Framework web para criação da API REST.
- **dotenv**: Gerenciamento de variáveis de ambiente.
- **Axios**: Cliente HTTP para fazer requisições à API de IA.
- **API GPT (ElectronHub)**: Serviço de inteligência artificial baseado no modelo GPT para geração de conteúdo.
